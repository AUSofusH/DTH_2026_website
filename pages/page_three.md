## A useful open-source project:

### Tesseract OCR Engine 

Tesseract OCR Engine is a tool for optical text recognition, and enables you to turn legible text in PDFs, images, and other file formats into plain text (Weil, 2026). Tesseract was originally created by Hewlett-Packard, and open-sourced in 2005, where it was further developed by Google until 2017. The software has since been augmented with a neural network to improve line recognition. The current lead developer is Stefan Weil (2026). 

### How could it help in my major? 

OCR is very useful for converting scanned or photographed images of books, text, and DRM protected documents into machine-readable text. These documents would otherwise require manual reading and copying, while also preventing the use of scrapers and LLMs for analysis and data collection. 

### The five checks: 

**License:** Tesseract is covered under Apache 2.0, which allows for the use and redistribution of the software, provided certain conditions are met, like retaining copyright notices and including a copy of the original license. (Tal, 2026). 

**Last change:** The latest commit was made on November 13th at 17:02. 

**Contributors:** Tesseract has 214 contributors and 6815 commits. 

**Issues:** Issues are answered within 1-2 days and quickly resolved. 

**Funding:** Tesseract has previously received grants from the German Research Foundation, from 2018 to 2020 (Gepris, n.d.). 


### My verdict: 
Based on the available information, I would absolutely use Tesseract, and I plan on using it in the future. If the software has issues, the lead developer and contributors are quick to address them, and an outage only prevents me from doing new OCR scans. I could leave it again if needed, as Google cloud (n.d.) has some OCR tools available for free.
