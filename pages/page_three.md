## A useful open-source project:

### Tesseract OCR Engine 

Tesseract OCR Engine is a tool for optical text recognition, and enables you to turn legible text in PDFs, images, and other file formats into plain text (Weil, 2026). Tesseract was originally created by Hewlett-Packard, and open-sourced in 2005, where it was further developed by Google until 2017. The software has since been augmented with a neural network to improve line recognition. The current lead developer is Stefan Weil (2026). 

### How could it help in my major? 

OCR is very useful for converting scanned or photographed images of books, text, and DRM protected documents into machine-readable text. These documents would otherwise require manual reading and copying, while also preventing the use of scrapers and LLMs for analysis and data collection.
